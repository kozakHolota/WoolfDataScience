# Homework 2 — Text Classification via LLM

Завдання демонструє підхід **few-shot prompting**: один клієнт (`OpenAIClient`) приймає JSON-шаблон відповіді та приклади, і класифікує довільний текст через OpenRouter API.

---

## Завдання

### Завдання 1 — Аналіз тональності

Вхід: повідомлення про дії співробітника.  
Вихід: ім'я особи та тональність повідомлення.

```json
{"person": "Наталія Коваль", "tone": "позитивна"}
```

Можливі значення `tone`: `позитивна` | `нейтральна` | `негативна`

---

### Завдання 2 — Визначення пріоритету продуктового баг-репорту

Вхід: повідомлення про проблему або зміну в продукті.  
Вихід: назва продукту та пріоритет.

```json
{"product": "Atlas", "priority": "високий"}
```

Можливі значення `product`: `Atlas` | `Core` | `Desk`  
Можливі значення `priority`: `високий` | `середній` | `низький`

---

### Завдання 3 — Категоризація новин

Вхід: новинне повідомлення.  
Вихід: короткий заголовок (до 8 слів) та категорія.

```json
{"title": "Новий модуль експорту PDF-звітів", "category": "реліз"}
```

Можливі значення `category`: `реліз` | `інцидент` | `рекомендація`

## Встановлення залежностей

```bash
pip install openai
```

---

## Запуск

1. Отримати API-ключ на [openrouter.ai](https://openrouter.ai) та встановити змінну середовища:

```bash
export OPENROUTER=your_api_key_here
```

2. Запустити з кореневої директорії `homework_2/`:

```bash
cd home_works/ai_agentic_systems/homework_2
python main.py
```

> Запуск обов'язково з директорії `homework_2/`, оскільки шляхи до файлів відносні.
